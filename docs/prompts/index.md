# 提示词中英对照库

> DeepSeek Harness（dsh）全部模型可见提示词，按模块分组。每个提示词含**英文原文、中文翻译、关键参数、Few-shot 示例、提示词链路、相关代码上下文**。

## 如何阅读

每个提示词文档遵循统一结构：

1. **元信息**：原文件位置（精确行号）、变量名、功能模块、调用场景、来源分类
2. **英文原文**：完整保留格式的原文
3. **中文翻译**：准确的中文对照
4. **关键参数**：占位符与变量的含义
5. **Few-shot 示例**：如有内嵌示例则列出
6. **提示词链路**：注入时机、order 位置、上下游关系
7. **相关代码上下文**：所在函数与机制说明

## 核心机制速览

DeepSeek Harness 的提示词不是单一文件写死的，而是由数十个插件**按 order 排序动态组装**：

```
harness:identity (-100) → harness:source (-99) → web-surface (-98)
→ persona (0) → code-only (99) → 工具指导带 (100–199) → 文件引用 (190)
```

动态上下文（沙箱 110 / 审批 115 / 子代理 120）作为 user 角色持久快照注入，变化时才更新。
